## MDMT 2.3.0

A review of the whole toolkit, with fixes in every tool. Some results change from earlier versions; those changes are marked **Changed**.

- **Words split at the end of a line are found again.** PDFs store a word hyphenated across two lines (`mill-` / `race`) with a hidden marker that hid both halves from Keyword Search, and from Named Entities, Relationships, Co-Words, Translation and RAGBot. MDMT now reads it as a hyphen and a line break, so `mill`, `race` and `mill race` are found. Counts for PDFs with such words go up.
- **Keyword Search:**
  - **Changed:** CSV cells that Excel would read as a formula now start with an apostrophe, so a context such as `-5 degrees` shows as text instead of `#NAME?`, and text in a PDF cannot run as a formula. Excel shows the apostrophe.
  - Keyword and filter files saved as "Unicode" (UTF-16) in Notepad are read correctly. They used to be read as nonsense, so nothing was found.
  - Sub-folders that cannot be opened are listed with the skipped files instead of being left out silently. The other tools do the same.
- **Translation:**
  - A PDF and a text file with the same name in one folder (`report.pdf` and `report.txt`) get separate translations (`report_translated.txt` and `report_2_translated.txt`). One used to overwrite the other.
  - **Changed:** Auto-detect no longer forces every file into an installed language. A file in a language without an installed model is listed as an error naming the language it found, and a file already in the target language is skipped. Before, with only French → English installed, a German file was "translated" from French, or copied unchanged and reported as English.
  - Underscores are kept: `file_name` no longer becomes `file name`.
  - Blank lines are kept, and headings stay separate from the following paragraph, also when translating through English.
- **RAGBot:**
  - A question longer than about 500 words no longer fails with "Truncation error".
  - **Changed:** At short context lengths, older parts of the conversation are left out when the passages and the question would not otherwise fit, so answers are no longer cut off after a few words or refused. A question too long for the context length gets a clear message.
  - A document saved while it is being indexed is indexed again next time. It used to keep its old passages for good.
  - Re-index waits until an answer has finished, reports if it fails, and no longer empties the index when the documents folder is missing (an unplugged drive, for example).
  - One unreadable file or broken link no longer stops the setup: it is listed with the files that could not be read.
  - Text without spaces, such as unpunctuated Chinese or long web addresses, is split into passages of the normal size, so all of it can be found.
  - Word documents: text in content controls (cover pages, tables of contents, template fields) is now read, and nested tables are read once instead of twice. CSV files with a blank first line are read.
  - A year in square brackets in an answer, such as `[1854]`, is no longer removed as if it were a citation.
- **Relationships:**
  - **Changed:** A passage that names more than 40 entities, such as a list or an index page read as one sentence, is left out and reported. It used to make the run seem to hang, and could write a CSV of tens of megabytes.
  - Chinese and Japanese texts now give relationships.
  - Your own `<name>_text.txt` next to `<name>.pdf` is processed and never overwritten. Text saved by an earlier run is recognized by its content, also for PDFs named in capitals (`Scan.PDF`).
  - Only the graphs drawn by this run are shown, and a run that finds no relationships replaces the earlier `relationships.csv` with an empty one.
- **Named Entities and Co-Words** skip the text files Relationships saved from PDFs, which were counted twice.
- **Co-Words and Relationships, other languages:** words in Hindi, Bengali, Thai and other scripts with vowel signs, and Arabic with vowel marks, are no longer broken into single letters. Sentences ending in `।` or `؟` are split correctly.
- **Co-Words** network lines are scaled, so graphs of long documents are no longer covered in grey.
- **OCR:** a PDF whose PDF/A conversion failed, or whose output failed the validity check, is reported as a problem instead of as done. The Windows build no longer flashes a console window for every page.
- **Downloads:** two downloads of the same model, for example from the Welcome page and the Downloads page, no longer break each other, and starting MDMT again no longer deletes a download that is still running.
- **Settings:** turning dark mode on or off no longer undoes settings changed since the window opened. A settings file that cannot be read for a moment is kept instead of being replaced with the defaults.
- **Linux browser mode:** cookies set by other programs on your computer no longer lock you out of MDMT ("This MDMT window has expired"). Two launches at the same moment open one MDMT.
- **Windows and macOS:** the "Quit anyway?" question no longer stays on after a job that ended at once. On Windows, a log file that another program holds open no longer makes jobs hang.
- **Licenses:** every build now includes a `licenses` folder with each bundled component's own license files, and `THIRD_PARTY_LICENSES` adds the licenses that were missing. The README now names the GPL-licensed libraries the apps bundle (the GCC runtime libraries, under the GCC Runtime Library Exception, and on Linux possibly libjbig) instead of saying there are none.
- The Linux menu entry works from folders whose names contain quotes, `$` or `%`, and uses an icon of the right size. The README gives the right location for the menu-entry script.
