## MDMT 2.1.0

- **Smaller downloads:** Linux 256 MB (was 1.2 GB), macOS 138 MB, Windows 231 MB. MDMT no longer bundles PyTorch.
- **Work keeps running while you browse:** every tool runs in the background with real progress (files done, current file, elapsed time), can be cancelled between files, and finishes with a summary, its charts and graphs, and a button to open the output folder. The sidebar shows what is running, and on Windows and macOS MDMT asks before closing while a job runs.
- **RAGBot, rebuilt:** answers cite the passages they rely on (click a source to read it), stream in as they are written, handle follow-up questions, and say so when your documents don't contain the answer. It uses Qwen 3.5 2B, or 4B on Apple Silicon Macs, where it runs on the GPU; the 0.8B model is no longer offered. Thinking mode gets the long context it needs automatically, and RAGBot tells you if an answer runs out of room.
- **Fully offline translation** with Argos Translate models, and **multilingual named-entity recognition** in 10 languages.
- **New Downloads page:** download or delete every model and language file, with progress and disk usage, or get everything at once with the Recommended setup on the Welcome page.
- **Every tool remembers its settings**, checks your folders before running, and supports dark mode throughout.
- **Linux** now runs in your web browser and is distributed as `mdmt-linux-x86_64.tar.gz`; Windows and macOS keep their native window.
- **Fixes:**
  - OCR now uses the languages you download.
  - Windows no longer crashes when started without a console.
  - Keyword Search's basic filter keeps accented and non-Latin letters, and its filter help describes what the filters do.
  - Relationships no longer counts text it extracted on an earlier run.
  - Model downloads wait and retry when Hugging Face asks them to slow down.
  - A damaged settings file no longer stops MDMT from starting.
- **Requirements:** macOS builds need macOS 15 or newer on Apple Silicon; the Linux build needs a distribution about as recent as Ubuntu 24.04.
