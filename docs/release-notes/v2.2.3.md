## MDMT 2.2.3

- **Keyword Search fixes:**
  - Arabic text that PDFs store as presentation forms matches keywords typed normally again (`مرحبا`), as do fullwidth letters and digits (`ＡＢＣ`, `１２`) and Hebrew and Armenian ligatures. 2.2.2 only converted Latin ligatures such as `ﬁ`. Symbols such as `™` and `²` are still left as written, so filters keep removing them.
  - A standalone accent before its letter, as PDFs made with LaTeX often store `café` (`caf´e`), is now joined to the letter: `caf´e` matches `café`, `M¨uller` matches `müller` and `Dvoˇr´ak` matches `dvořák`, with or without the basic filter. This changes 2.2.2, where with the basic filter `caf´e` matched `cafe` and not `café`. Because `´` is also typed as an apostrophe, it is only joined to a vowel: `it´s` is still `its`.
  - Filters now remove characters as they appear in the PDF: `ﬁ` in the filter removes the ligature, and a letter in the filter is also removed where a ligature contains it. An `é` pasted into the filter as `e` plus a separate accent removes `é` instead of every `e`.
  - A keyword that the filter removes completely, listed twice, is searched and reported once. It used to get a second CSV named, for example, `++ (2)`.
  - Any error while drawing a chart now loses only that chart. Before, some matplotlib errors stopped the whole search. A chart that cannot be saved no longer leaves a partly written file, or one from an earlier search, in the output folder, and the results say which chart (pie or bar) is missing.
