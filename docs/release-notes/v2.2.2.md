## MDMT 2.2.2

- **Keyword Search fixes:**
  - Filters work again on characters such as `™`, `²` and `…`. In 2.2.1 the text was rewritten before the filter ran (`™` became `TM`), so these characters were no longer removed: with `™` in the filter, `acme™` no longer matched `acme`.
  - Words with a standalone accent, as PDFs made with LaTeX often store `café` (`caf´e`), are one word again. In 2.2.1 they were split in two, so with the basic filter `cafe` found nothing. Ligatures (`ﬁ`) and accents stored as separate marks still match, as in 2.2.1.
  - When two keywords match the same words, such as `york` and `york.`, or `c++` and `c#` with the basic filter on, they are still counted once, and the results now say which keyword was counted with which. Before, the second keyword disappeared without a word. Keywords that the filter removes completely are named too.
  - With a filter that removes capital letters, `York` and `york` no longer match the same words, so both are searched; the second is named `york (2)`.
  - A PDF whose charts cannot be saved is listed with a warning instead of among the skipped PDFs, since it was searched and counted. If the total charts cannot be saved, the search still finishes and says so.
