## MDMT 2.2.0

- **Keyword Search includes sub-folders**, like the other tools. The CSVs name each PDF by its path within the input folder, and the charts of a PDF in a sub-folder go in the matching sub-folder of the output folder. Results for PDFs at the top of the folder keep their names.
- **Keyword Search counts are more accurate.** Some counts change from earlier versions:
  - Every match is counted once and has exactly one row of context in the keyword's CSV. Before, the counts and the context rows could disagree: a keyword at the start or end of a page, or `mill race` written as `mill-race`, got context but no count.
  - Keywords are plain text matched as whole words. A `.` in a keyword no longer matches any character, and keywords such as `c++` no longer stop the search.
  - Punctuation at the edges of a word no longer hides it: `york.`, `(york)` and `york;` all match `york`. Context rows still show the text as written.
  - The basic filter keeps hyphens, so `mill-race` no longer becomes `millrace`, and hyphenated keywords now match with the filter on.
  - Spaces around keywords and blank lines in the keyword list are ignored.
- **Keyword Search context length** includes the keyword and is split evenly. The default of 5 saves two words before the keyword and two after; it used to save four words in all. Even lengths save what they did before.
- **Keyword Search lists the PDFs it skipped**, as the other tools do: scanned PDFs without a text layer (run them through OCR first) and PDFs that cannot be read. A PDF that cannot be read no longer stops the whole search.
- The About page explains how Keyword Search matches keywords.
